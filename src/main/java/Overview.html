This is the overview system documentation for the New York Electronic HIV/AIDS Monitoring System (NYEHMS); see below the package list for the complete text of this overview.

NYEHMS is a web application maintained and deployed by the New York State Department Of Health to track every case of HIV/AIDS of residents of New York State. It is maintained by the Systems Development Unit of the Bureau of HIV/AIDS Epidemiology (BHAE) which is part of the Division of Epidemiology Evaluation and Research (DEER) which is a unit within the AIDS Institute.
